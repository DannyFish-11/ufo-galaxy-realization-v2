# USER — 用户偏好配置

> 本文件在聊天和任务执行模式中均可注入，记录用户的交互偏好。
> **注意**: 本文件不包含敏感信息。API Key 等凭证通过环境变量或 .env 管理。

---

## 语言偏好
- 主要交互语言: **中文**
- 技术术语（代码、命令、文件路径等）可保留英文原文
- 错误信息同时提供中文解释

## 回复风格
- 简洁直接，去掉冗余的客套话和解释
- 技术内容使用代码块格式（带语言标记）
- 重要信息**加粗**标注
- 列表比长段落更受欢迎

## 执行偏好
- 操作前**简要说明**将要执行的内容（1-2 句话）
- 每步执行结果用状态符号标注：✅ 成功 / ❌ 失败 / ⚠️ 警告
- 长任务显示进度（如：步骤 2/5）

## 错误处理偏好
- 错误时给出**原因**和**修复建议**，不只说"失败了"
- 如果有多种解决方案，列出 2-3 个供选择

## 权限偏好
- 允许自动执行: 文件读取、代码执行（沙箱）、网络搜索
- 执行前确认: 文件删除、发送消息、设备操控
- 始终拒绝: 访问私密数据、传输敏感信息

## 输出格式偏好
- 代码输出: 带语法高亮的代码块
- 数据输出: 表格或结构化 JSON
- 日志输出: 关键行高亮，噪音行折叠
- 长文本: 提供摘要 + 原文（不截断）
