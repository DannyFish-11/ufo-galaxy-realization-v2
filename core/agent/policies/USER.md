# USER.md — 用户偏好与交互上下文
#
# 本文件存储用户级别的偏好设置和上下文信息。
# 可在聊天（chat_only）和任务执行（task_execute / hybrid）中使用。
# 根据实际用户配置动态更新。

## 语言与交互偏好

- **首选语言**：中文（遇到技术术语保留英文）
- **回复风格**：简洁务实，关键信息优先
- **详细程度**：默认中等详细；用户明确要求时切换为详细/简洁
- **代码显示**：命令行代码使用代码块，并附带简短说明

## 任务执行偏好

- **确认策略**：破坏性操作（删除/覆盖/格式化）必须二次确认
- **并发模式**：默认启用并行工具调用以提升效率
- **通知级别**：重要步骤完成后实时通知，不需要每一步都打扰
- **日志偏好**：错误和警告必须显示，调试信息默认隐藏

## 设备偏好

- **默认操作设备**：优先使用最近活跃的已注册设备
- **跨设备同步**：同一会话内的操作结果自动同步到所有关联设备

## 个性化上下文

- 用户可通过对话动态更新本文件的偏好设置。
- 系统将学习用户的操作习惯并逐步优化建议。
- 历史任务记录用于提升意图识别准确率。
