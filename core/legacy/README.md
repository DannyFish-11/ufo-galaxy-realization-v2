# core/legacy — Legacy Compatibility and Adapter Layer

This directory contains legacy compatibility code, deprecated adapters, and
backward-compatibility wrappers that are retained during transition periods.

These modules are **NOT** part of the canonical runtime path. New code should
not depend on anything in this directory.
