# 执行不猜 · 权限一套门 · 边想边说边改 —— 总体设计

> 2026-10-28 与所有者逐步讨论后定下。四项取舍所有者已拍板（见 §0）。
> 这份文档是**实现的依据与进度账**：每一轮接着做时先看最后一节「进度」。

## 0. 前提与四项决定

模型是一面镜子：它说「有把握」不担保任何事。系统的可靠来自它**外面**的三样 —— 事实从哪来、谁能批、做完谁核。

所有请求只分两条路，判据只有一条：**这次输出会不会改变外面的世界**（与 `core/semantic_anchoring.py`
「会改变控制流的读取走对象层」同一条判据的延伸）。

```
请求 ─→ 会改变外面的世界吗?(动设备 / 文件 / 权限 / 对外发送)
         ├─ 会 → 执行路:事实齐 → 权限过 → 落手 → 独立核对 → 记账      (不猜)
         └─ 不会 → 回答路:查 → 指准 → 综合 → 边说边核 → 记账            (有据)
                              └─ 开放问题且证据不足 → 猜(标出来) → 查 → 判
```

所有者拍板的四项：

1. **电脑面板能批高风险操作**：电脑发起的在电脑上批，手机 / 手表发起的在那台设备上批。
2. **批一次默认记「同一个动作 + 同一个对象」到这次会话结束**；「一直允许」要人明确选，面板能撤。
3. **语音里只当场口头更正实质性错误**，每轮最多一两次；查不到的不念（文字里标）。
4. **面板原地改时留原文**：划掉、可展开。

不做的：不加新开关（常数进 `core/tuning.py`）；不改验证器；不碰跨设备那套语义（#1667 已按所有者定义合进 main）；
不宣称消灭幻觉 —— 只让它落进「候选」格子、能被核出来。

## 1. 执行路：不猜，权限要齐、要稳

### 1.1 动手前事实齐了才动
- 设备在不在线、有什么能力：UCM / 设备注册表；走哪一级：`core/windows_execution_arbiter.py`（视觉永远最后）；
- 引用型参数（设备号、节点、路径、窗口）必须对得上对象层，对不上不派发、回喂错误（`core/tool_call_validator.py` 规则层）；
- 系统层权限当事实登记、执行前查，缺了说缺哪个；
- 缺任何一样事实：照实失败，不补、不模拟（第 7 轮节点那批的做法）。

### 1.2 权限：改之前的样子（读代码 + 实测，2026-10-28）

| 问题 | 现状 |
|---|---|
| 两套审批并存 | A：`core/tool_permissions.py` + `core/interaction/high_risk_confirmation.py`，按工具名分级，只问手表/手机，每批一次只管这一次；B：`core/autonomy_policy.py` + `/api/v1/approvals`，按节点动作，`GALAXY_AUTONOMY` 三档，仅此次/本会话/永久 |
| 电脑前的人批不了 | A：没连手表手机直接拒（实测「没有已连接的设备可以询问」）；B：待批队列面板上没有入口 |
| 同一次调用问两遍 | `node__…__execute` 先过 A（critical），进 `invoke_node` 再过 B（声明白名单的设备节点） |
| 门禁出错就放行 | `core/openclawd.py` 与 `core/capabilities/canonical_dispatcher.py` 的 `except: 放行`；`core/node_invocation.py` 权限门 / 拨盘门出错 `proceeding` |
| 授权文件放错地方 | `.galaxy_grants.json` 写在仓库根，不认 `GALAXY_DATA_DIR` |
| 授权粒度 | 键只有「节点:动作」，没有对象；「本会话」其实是进程存活期 |
| 自家工具族没分级 | `engineer__` / `computer_use__` / `github__` … 一条规则都没对上，按默认「中等、直接放行」 |
| 各处各写一份「问完再试」 | `core/smart_home_tools.py::_approve_on_watch`、`core/device_onboarding/agent_tools.py` |

### 1.3 权限：目标
1. **一个审批入口** `core/approval_gate.py::request_approval()`：
   查授权 → 判在哪问 → 问 → 等 → 落授权。所有门（工具门、节点拨盘门、智能家居、设备接入）都调它。
   `tool_permissions` 只回答「这是什么风险级别」；`high_risk_confirmation` 退为「在手表/手机上问」的那一种问法，
   只有明确批准才放行的性质原样保留。在电脑上问的、没人在等而排队的，都进同一个 `ApprovalRegistry`，
   面板看到的是电脑这边的全部；在手表 / 手机上问的只在那台设备上出现。
   设备接入（`core/device_onboarding/agent_tools.py`）那一问属于跨设备那批，本线不改。
2. **授权按「动作 × 对象」记**：键 `node:<编号>:<动作>@<对象>` / `tool:<工具名>@<对象>`；对象从参数里取
   （设备号、路径、实体、窗口、应用……），取不到就是「这个动作」本身。旧的「节点:动作」永久授权照认。
3. **「本会话」= 这一段对话**：会话授权绑会话 id，换一段对话不算；没有会话 id 的（REST 直调）退回进程期。
4. **从哪发起就在哪批**（`core.liminal_activity.current_runtime_session()` 的 `desktop_originated` / `origin_device_id`）：
   - 电脑发起（含后台自发、说不清的）→ 电脑面板：WS 推 `type="approvals"`（只带摘要，不带令牌），
     面板 `GET /api/v1/approvals` 取令牌后点批；灵动岛一张「等你批准」卡（`action="panel"`）；
     桌面外壳一个都没连上 → 立刻判不批准（不白等一个注定超时的周期）；
   - 手机 / 手表发起 → 在那台设备上问（`request_human_decision`，只问它）；它不可问 → 退回电脑面板；
   - 批准默认落「本会话」档；面板另有「只这一次」「一直允许」。
5. **一次调用只问一次**：工具门批过的，同一次调用里的节点拨盘门认（上下文里记一次、用一次就消）。
6. **处处出错即拒**：门禁自身出异常 → 不执行并说原因（节点门：读操作照放，写操作拒）。
7. **授权文件进数据目录**：`data_path_or_legacy("approval_grants.json", <仓库根>/.galaxy_grants.json)`。
8. **补全分级表**：自家只读工具登记 SAFE；`github__install`（装第三方代码）与 MCP 的删除 / 跑命令类
   登记 DANGEROUS/CRITICAL 要确认；`devices__` 那族不在本线改。
9. **不加开关**：「谨慎 / 引导 / 自主」三档本来就有。

### 1.4 落手与核对：已有，不动
仲裁器落手；四值裁决核对；Computer Use 自报做完另截一张屏核；核不过后台再试一次，还不行进「没收口的结果」。

## 3. 回答路：边想边说边改（核对不拖慢交互）

**说话本身就是核对的时间窗**：`core/streaming_speech.py::IncrementalSpeaker` 边生成边念，第 N 句在播时第 N+1 句已经
生成、在排队合成 —— 核对塞进这段排队时间，多数句子零额外延迟。第一句没有窗口，而第一句通常是开场，不用核。

```
模型流式出字 ─→ 分句(每句一个编号) ─→ 表达线:面板文字 / 语音 / 灵动岛 / 手表
                     │                      ↑ 修订(原地改 / 口头更正)
                     └─→ 核对线:要不要核 → 并发去核 → 结论
                                                     │
                  生成线 ←── 实质性错误:在句界打断,带着更正接着说
```

### 3.1 要不要核（规则，不调模型）
要核：含数字、日期、版本、专名、设备状态的句子；「已经做好了」；标了「猜」的。不核：开场、过渡、复述、语气。

### 3.2 去哪核（按快慢分级，并发，每轮有上限）
| 核什么 | 去哪核 | 多快 | 能不能赶在说出口前 |
|---|---|---|---|
| 设备状态、任务结果、「做好了」 | 对象层、真相链四值裁决 | 毫秒 | 能 |
| 记忆、知识、文献 | 记忆检索、本机 arXiv | 百毫秒 | 多数能 |
| 时效性资讯 | 联网搜索 | 秒 | 不能，只出事后修订 |
| 查到了但对不对得上 | 换一个模型裁决 | 秒 | 不能 |

结论：证实 → 不改（悬停看出处）；驳倒 → 修订；查不到 → 文字标「未核实」，语音不念。

### 3.3 错了怎么改
| 时机 | 做法 |
|---|---|
| 还没说出口 | 作废这句和后面排着的（`IncrementalSpeaker` 代数作废），从这句起打断续写 |
| 已说出口、还在生成 | 下一个句界打断，把「第 N 句与某来源不符，应为 Y」当观察喂回去接着说（同工具轮的暂停 → 续写） |
| 这一轮已经结束 | 给那条消息挂勘误：面板原地改、原文划掉可展开；岛上一张「刚才的回答有一处更正」；人还在对话里就下一轮开头补一句 |

### 3.4 各交互面
| 面 | 能收回吗 | 规矩 |
|---|---|---|
| 面板文字 | 能 | 原地改，标「已更正」，原文可展开 |
| 语音 | 不能 | 排队中换掉；换不了口头更正一次；每轮最多一两次；人一开口就丢掉待念的更正 |
| 灵动岛 | 能 | 只放「有一处更正」短卡 |
| 手表 / 手机 | 对话能、通知不能 | 对话原地改；通知只发核过的最终版 |
| 记忆 | 能 | 被驳的句子带「已驳」写入，不当事实召回 |
| 动手 | — | 句子永远不触发动作；「做好了」等四值裁决出来才说 |

### 3.5 协议（兼容旧客户端）
SSE 新增 `revise` 帧（句子编号、原句、新句、结论、来源）；`done.response` 仍是权威全文且已含更正；
晚到勘误走 WS `revise`，按消息编号定位。语音更正走 `speaker.feed()`，换排队句走 `reset()`。

## 4. 开放问题才猜：猜作为标注句进流
猜想当场作为**标了「猜」的句子**说出来，后台并发去核（猜想当检索词 —— HyDE），核完补一句跟进；
裁决换一个模型、只看「猜想 + 证据」，提出者自报不算（同 `check_verdict_independence`）。
猜想结果用类型化字段存（落 `core.data_paths`），不进决策路径（加进 semantic_anchoring 的扫描）；
要动手就转执行路，从事实层重来。预测类记下来到期对账，结果进账本。

## 5. 验收（每条一个测试钉住）
- 没连手表手机时电脑面板能批高风险操作；批了才执行，拒绝 / 超时都不执行；桌面外壳没连上立刻不批准；
- 手表发起的只在手表上问；
- 同一次节点调用只问一次；
- 门禁抛异常时不执行；
- 授权落 `GALAXY_DATA_DIR`，旧位置已有的照认；会话授权换一段对话不算；对象不同不算；
- 引用型参数对不上注册表不派发；
- 注入的知识带时间；
- `revise` 帧与 `done` 全文一致；被驳的句子不当事实进记忆；「做好了」等裁决；
- 猜想不进决策路径；裁决者不是提出者。
