# 手机端测

设计见 `docs/DEVICE_SELF_DESCRIPTION_DESIGN.md` 6.3。手机本地循环（截图 → 端侧视觉模型规划 → 定位 → 无障碍执行）做得对不对，
只能拿真截图、真模型来测。方法参考面壁 AgentCPM-GUI 的评测，判定细则照抄他们的代码，数字能直接和公开数字比。

## 四层

| 层 | 测什么 | 在哪跑 | 怎么跑 |
|---|---|---|---|
| L1 定位 | 截图 + 一句描述 → 点在哪；点落在目标控件框里算对 | 电脑 | 安卓仓 `tools/eval/README.md` |
| L2 单步动作 | 指令 + 当前截图 → 下一步动作；TM（类型对）、EM（类型和参数都对），任务成功率、进度 | 电脑 | 同上 |
| L3 端到端 | 真机上一句话做到底：成没成、步数、卡住几次、做不了时有没有照实停下 | 真机 | `docs/REAL_DEVICE_CHECKLIST.md` 第 4 节 |
| 端侧开销 | 每步时延、模型加载时间、峰值内存、30 分钟耗电和温度 | 真机 | 同上 |

- L1、L2 跑的是 App 自己的 `VlmPlanner` / `VlmGroundingEngine`（同一套提示词和解析），连电脑上的 `llama-server`，载 App 用的同一份 GGUF。
- 数据是面壁的中文 App 基准 CAGUI：定位部分 Fun2Point、Text2Point，智能体部分是多步任务。
- 同一套数据也用来选端侧模型。换模型、换量化、改提示词之后都要跑一轮。

## 每一轮
